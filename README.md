# Hydrology Next website

Static website for the Hydrology Next group, CNR-GEO (Perugia, Italy).

## Publishing on GitHub Pages

1. Create a repository, for example `hydrology-next`.
2. Upload everything in this folder, keeping `assets/` as a folder.
3. Go to **Settings → Pages**, set **Source** to `Deploy from a branch`, branch `main`, folder `/ (root)`, and save.
4. After a minute the site is live at `https://<username>.github.io/<repository>/`.

## Files

- `index.html` — home page
- `people.html` — people, collaborators, values
- `projects.html` — timeline and project tables
- `assets/` — logos and photographs

## Editing

Each page is a single HTML file. Text can be edited directly in GitHub: open the file, click the pencil icon, change the words, and commit. The site updates within a minute.
