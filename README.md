# Hydrology Next

Website of the Hydrology Next group, Institute of Geosciences (CNR-GEO),
National Research Council of Italy, Perugia.

Live site: https://hydrologynext.github.io/

## Files

- `index.html` — home: research, method, impact, open data, news, publications
- `people.html` — people, collaborators, values
- `projects.html` — project timeline and tables
- `assets/` — photographs and logos
- `.nojekyll` — tells GitHub Pages to publish the files as they are

## Publishing on GitHub Pages

1. Upload everything in this folder to the repository root, keeping `assets/` as a folder.
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Wait for the green tick under the Actions tab.

## Editing text

Open a file on GitHub, click the pencil icon, change the words, commit.
The site updates within a minute.
